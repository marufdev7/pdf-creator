# FolioForge

FolioForge is a local-first React application for composing text, code, screenshots, outputs, and charts into paginated PDF documents.

## Run locally

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run test
npm run test:e2e
npm run build
```

Projects autosave to IndexedDB. Use the archive button in the header to download an editable `.pdfproj` package, or **Generate PDF** to render and download the final document.
